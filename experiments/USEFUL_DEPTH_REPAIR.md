## Structural audit

1. Constructor gain0.5/sqrt(D) changes existing stages when D changes. D2→D8 halves their correction scales. StageGainTokenCore and complete-learner migration already preserve acquired weights/gains/moments/versions at unchanged depth. This identifies a configuration confound, not a proven cause of the observed quality deficit.
2. Every native stage applies channel mixing, hard races and delivery delay. Setting a residual gain to zero is not an identity stage. The final stage's messages and arrival times become next-token context, aligned through the last stage's transport parameters. New depth therefore changes a recurrent dynamical system, not merely a feed-forward residual stack.
3. The teacher selects one token/depth/head alternative when enabled. At fixed teacher probability and updates, added layers share a fixed audit budget. Full-support weighting preserves the declared conditional raw-credit mean; it does not preserve variance or useful actual Adam updates as depth grows. Factual credit and unrealized-route credit require distinct measurements.
4. Existing depth/reference comparisons also differ in accessible readout features and total work. Do not attribute a readout advantage or extra fitting to depth itself.

## Selected construction to investigate

Add optional native temporal computation with an initial null path that preserves the parent's actual messages, clocks, next-token feedback and RNG stream. Preserve old gains, weights, moments, bank ownership and carried state. A null path must introduce no extra delivery delay or changed context transport. New branch clocks/state/parameters remain distinct and paid.

The new stages must be learnable at this neutral starting point. Zero output maps suppress internal factual gradients until they move. Our alternative-route teacher offers a more native route: explicitly score a hypothetical activation of the new temporal computation and differentiate its consequences while the factual path stays unchanged. This retains hard temporal competition, addressed persistent memory, separate keys/values and credit to unrealized alternatives. It is a proposed integrated construction; existing helpers do not yet certify it. Compare error-conditioned feature seeding from THEORY_GUIDED_TEMPORAL_VARIANT_SELECTION if alternative credit proves ineffective, rather than introducing a seed grid.

Inference costs include discovery, selected new work, messages and actual added latency. Learning costs include losing alternatives, replay, state cloning and optimizer work. A dormant branch is capacity, not zero discovery/training cost. No dense carrier substitution or shallow readout shortcut is proposed.

## Decisive contracts and experiment

First demonstrate exact old predictions, routes, delivery times, persistent context and RNG at neutral growth; exact old-parameter updates under the preserved learner; independent new storage and correct checkpoint ownership. Then demonstrate nonzero, useful credit to new internal state/write/clock parameters through activated alternatives. Changed bank schemas require recalibrated local caps, not copying saved caps blindly.

Measure stage response and loss sensitivity to actual temporal-message/arrival perturbations, factual cotangent transport and alternative-credit variance per charged work. Raw gradient norms and receiver activity alone do not identify useful depth. Relate stage novelty to final prediction benefit through causal interventions.

One paired acquired-parent continuation versus grown successor is the next architectural test after these gates: same additional data/order and explicit full work, with parent weights/optimizer/state retained. Report

    added-depth gain = NLL(continued parent) - NLL(grown successor).

Improvement relative to a frozen parent includes continued training and is not an added-depth effect. Select on development data; preserve public scoring protocol. If new stages earn no predictive benefit, diagnose information transport and credit before increasing layer count, width or acquisition. Longer-term sparse optional depth must be evaluated against sequential stage latency and measured resource cost, not layer count alone.
