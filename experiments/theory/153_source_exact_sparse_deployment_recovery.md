## What is retained mathematically and numerically

For fixed source program S, represented weights W, input bytes B, initial state
Z and random stream ξ, isolation preserves the program F(S,W,B,Z,ξ). It restores
the computational delays, factorized races, hard addressed writes, private
memory, separate keys/values, channel transport and trained counterfactual-credit
construction. Available state and all-key scoring are not removed. Weight
prepacking is paid once per declared static weight version; it does not add a
concurrent serving or online-learning interface.

The key-cache invariant remains R_u=K_u+A_u m_u for stored private memory m_u.
Only the selected write changes that slot's cached read. This premise belongs
to this member's lazy-memory program; it is not a theorem for every temporal
operator in the family. Keeping the historical implementation also keeps its
observer's state/race contract meaningful. It does not validate the newer live
`SparseStepper` implementation or its incremental API.

Identical source/weight/data bytes alone do not guarantee FP32 route identity
across libraries, precision or reduction orders. The unchanged numerical gates
therefore remain mandatory: twelve synthetic plus four actual-trained FIT
cases, all active winners, final state/cache, mutation/version/RNG contracts;
paired DEV prefixes; then every full-split logit and saved BPC reproduction.
FP32 logit atol/rtol remain1e-4, paired and saved full-split BPC tolerance1e-5.
Promoted FP64 means the same represented trained weights, not a new FP64 fit.

Scoring retains seed314159, lane grouping, reset-per-window state, exclusive
stop and first-window/full versus later-window/second-half accounting. Each
restricted full split still scores999936 targets. Warm-context and both
backends' evaluated positions are paid; neither timings nor target omissions
are redefined to obtain a favourable result. The new full text8 byte hash
binds future validation, not the historical producer's previously unhashed
dataset. Reproducing its saved quality is a separate gate.
