private states store more distinct histories. Primary arms are shared-rule
U4 and U16; the existing private-rule U4 result is a diagnostic reference,
not a matched control. Keys, memory-key reads, clocks, retention rates and
frequencies remain private. Input/output/gate/control maps are shared within
each depth/head. Temporal transport, races, persistent messages and the actual
future alternative-write teacher remain the intended integrated recipe.

Both arms construct the same canonical U4 model. U16 makes four independently
stored replicas per address, shifts each initial clock bias by -log(4), and
preserves shared maps/readout and construction RNG. For unclipped zero-memory
scores s, each replicated hazard is exp(s)/4; their group sum is exp(s).
Consequently group selection probabilities and the first-arrival distribution
agree initially. This is distributional equivalence, not identical sampled
routes. The current kernel clamps scores before racing: equivalence requires
both canonical and shifted scores strictly inside [-12,12], temperature one
and zero free-address bias. Deterministic all-ones noise is not equivalent.
These conditions must be measured on the initial fit population before using
the clock-control claim. Writes and private learning then break replica symmetry.

count. Discovery scores four times as many keys. Private-bank gradients,
