# Event-conditioned future credit: what depth sharing and hard queries buy

The width32 failure is a representation and intervention result, not a theorem about learned credit. Its structured mean/RMS field loses event/error covariance: generally sum(q_t x_t^T) differs from mean(q_t) mean(x_t)^T. Actual frozen-core/head-only control performs better atwidth32. Width16 shows a positive deep-learning contribution. This motivates retaining event-indexed forward packets and learning their responsibility jointly across layers.

Let P_t be an immutable packet from the arrived block: native intermediate states, module inputs, elapsed gaps, observed marks and local terminal error cotangents. A connected temporal credit function builds a global context g_j from the reverse ordering of this already observed block. A shared typed decoder supplies q_l,j=f_psi(g_j,h_l,j,h_l+1,j,c_j,l/D). For linear producer W_l, an issued update has G_l=(1/Q) sum_{j in A} q_l,j (T_type x_l,j)^T. Trainable T_type transports the input basis; q is a learned responsibility, not assumed to equal a backpropagated gradient. Embedding rows use observed mark identities. Vector parameters have typed event-conditioned updates. Decoder and transport sharing makes parameter count largely independent of depth; retained packets and layer application still cost O(D L d), and dense numerical writes are paid. No asymptotically sparse total-learning claim follows from four queries alone.

A is an ordered subset sampled without replacement. At each choice, pi=.99 softmax(logits among remaining)+.01/remaining_count. Full support lets the policy discover initially unhelpful events; query likelihood includes every draw. The objective is the actual loss on the subsequently observed block after the finite issued update, J(psi | s,P)=E_A L_f(theta'_psi,A). Incoming actor and optimizer state s are detached; this is a conditional one-step learning objective. Its derivative is

    grad J = E_A[grad_psi L_f(theta'_psi,A) + (L_f(theta'_psi,A)-b) grad_psi log pi_psi(A)].

The reference b is future likelihood with the old deep weights and the same updated heads. It depends on the future observation, but is action-independent and detached from psi, hence E_A[b grad log pi(A)]=0. For a predictable Bernoulli teacher I with probabilityp=.25, multiply this gradient by I/p. Numerical prediction never depends on whether the teacher fires. Compute and cache factual cotangent/head gradients before replaying the reference, which overwrites actor forward metadata. Consume all saved activations from versionv before updating psi or issuing versionv+1.

Enumeration on a real depth4 native actor, with two eligible single-event actions, checks both the probability derivative and continuous update derivative. The maximum discrepancy is3.00e-16; future losses differ3.66e-4 and query gradient norm3.09e-4, excluding a vacuous zero-gradient pass. This is an objective-correctness result. Better future prediction and complete work-to-quality are separate empirical endpoints, tested first on the failed width32 regime and thenwidth16. Train/DEV blocks are independent episodes; no chronological-market learning or within-episode persistent meta-state result is inferred.

The constructive path to economical depth is shared representations of useful intervention effects, with event covariance retained, and future-value allocation of paid queries. It is not making credit tiny by fiat. Current retained capacity can exceed actor size, and full input transforms/replays can cost more than exact native backprop. The registered comparison charges those costs and retains strong nativeAdamW and acquired-core/head-only references. Future integration requires hard optional actor routes, counterfactual alternatives and event-local updates, plus sequence-continuous evaluation where drift is causal.
