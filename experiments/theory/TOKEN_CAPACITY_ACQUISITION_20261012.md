## Conditional acquisition model and decision thresholds

To reason before an exhaustive scaling grid, posit—not infer from the current fits—the risk model

    R(U,N_eff) = R_floor + a U^(-alpha) + b U/N_eff + D(U),

with a,b,alpha positive. The first term assumes addressable capacity reduces unresolved context interference; the second assumes approximately balanced private learning with finite effective experience; D includes tracking/credit error. They are testable assumptions, not a scaling law for this family. For fixed D, differentiating gives U_star = (alpha*a*N_eff/b)^(1/(alpha+1)). Larger effective experience therefore changes the preferred capacity even when selected activity is fixed. For weighted independent observations with common noise variance, N_eff = (sum_i w_i)^2 / sum_i w_i^2. Correlated observations require the covariance-weighted denominator sum_ij w_i*w_j*Cov(error_i,error_j)/sigma_squared instead; raw token count alone is insufficient. Unequal route demand requires route-specific effective counts and errors rather than the balanced U/N_eff approximation.

Under this model, pool8 improves pool4 exactly when

    a*(4^(-alpha)-8^(-alpha)) > 4*b/N_eff + D(8)-D(4).

This gives the acquisition threshold that a small-data verdict can miss. If the left side is no larger than the tracking-error difference, additional data alone does not repair that member. The two registered sizes test the direction of the difference; they cannot identify these coefficients or certify an asymptotic exponent.

Compute must be included separately: with linear all-key discovery, W/N contains a term proportional to U, although selected writes stay fixed. A growing U_star then raises discovery work per target. Asymptotic capacity beyond activity needs learned/bounded candidate discovery, amortized reusable credit or another measured sublinear discovery mechanism. Pool8 currently scores all32keys/target: this experiment tests useful capacity, not bounded discovery. The winning region is a joint quality/work condition, not capacity alone.

Capacity-choice estimators can eventually learn continuation advantage Q(state,U,budget) from source-addressed paired acquisitions, with the actual future task loss supplying the terminal teacher. These fresh pool4/8 fits change initialization and do not supply a same-learner expansion intervention. Packed bank tensors change shape: the existing strict optimizer-expansion helper intentionally rejects that transport. A future warm-start expansion needs explicit slice/moment/state mapping and a retained-route contract before it can supply those causal policy targets. This finite observed-loss teaching endpoint closes the estimation loop without adding a trainer of the trainer.

## Implemented storage path for acquired-learner expansion

ExpandedTokenCore retains every original packed parameter leaf and adds separate extension_banks leaves; _stacked concatenates receiver views for actual temporal computation. The strict optimizer_for_expanded_model can therefore copy original moments/groups without changing their shapes or ages, while extension leaves acquire state on their first update. Numerical state copies old memories/arrival times/seen masks and pads empty unseen new receivers. Tied processing reuses the original leaf; independent keys and other private fields get extension leaves. Cyclic cloning is explicit initialization, not learned similarity or a trained recruitment policy.

This changes the candidate pool, probabilities and RNG layout. Retaining old leaves/state does not imply original inference trajectories. The registered component witness acquires an integrated proper-token actor, checks isolated old-leaf Adam continuation, then activates an actual new receiver and checks nonzero gradients and independent Adam age. It waits behind the current fresh capacity pipeline. No warm-expanded quality fit is admitted before that receipt; current fresh fits retain the immutable original core.
