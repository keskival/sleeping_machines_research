# Stabilized frontiers: give each abstraction level a composition job

15 October 2026. New architecture, numerical contracts and no-fit resource gate.

## Failure being addressed

The successful tiny native FIT probe queries every lower memory directly into
the root. It demonstrates useful content, but gives the root a bypass around
intermediate compositions. Also, immediate upward notifications can reach a
parent before its children have integrated the other parts of the scene.
An active deep gradient is insufficient evidence that levels represent wholes.

Preserve the strongest all-level reader as an available construction. Add an
explicit adjacent-memory composition schedule, with identical native parameters:
after raw events drain, query level 0 memories into their level 1 parents; drain
those responses and publications; then query stabilized level 1 memories into
level 2, continuing upwards. Only the final native memory generates the output
at its pure race time. No labels, hidden part identities or raw-input shortcut
are inserted into these query rounds. All observed evidence was already available.

This is a finite chronological reference schedule. Its drain barriers are an
implementation restriction, not a claim of asynchronous hardware execution.
Ordinary upward event publication remains active. Persistent addressed state,
separate keys/values, independent native receipt races, local counterfactual
credit and pure emission-timer credit are retained. Policies remain geometric.

## What this changes mathematically

Write M_l for the complete learned memory frontier at level l and Q_l for a
round that delivers child views to their parent. The round obeys
M_(l+1)^+ = F_(l+1)(M_(l+1)^-, Q_l(M_l^+)).
Thus a parent consumes a child that has already undergone its own composition
round. The terminal explicit read only receives level D-2, rather than every
M_0,...,M_(D-2). This is a changed information path and computation schedule,
not a claim that existing states are sufficient statistics for future tasks.

For ordered parts a,b, a commutative sum can lose their arrangement. A reusable
compositor must preserve task-relevant relative pose or order in its messages
and learned state. The native message already carries relative pose and source
level; the new test asks whether learning actually uses this information.
Side-effect-free child reads preserve reusable state across parent hypotheses.

Geometric support doubling is not a semantic-level proof: at 128x128 resolution,
the current eight dyadic levels include upper unary consolidation. Eight object
levels/four native stages each must not be described as eight independently
verified semantic abstractions. The synthetic test starts with three genuine
nested arrangement levels; deeper task hierarchies follow successful transfer.

## Costs and the next engineering decision

If n_l active children are queried from level l, the explicit query count is
sum n_l, as for the all-level root read. Work is not equal: a frontier response
at l+1 also cascades upward through ordinary publications. Extra receipts scale
as sum n_l (D-l-1), versus approximately sum n_l for direct terminal reads.
Actual address occupancy, native depth, timers and candidate work must be counted.
This variant buys composition opportunities at a potentially substantial cost;
no efficiency or quality gain is inferred from its structure.

The no-fit gate reuses acquired native weights and measures one full TRAIN
scene, all eight levels' gradient support, candidate/update/publication counts,
wall/RSS and complete drainage. No semantic quality is scored using the old
11-class head. If repeated upward publication dominates, decouple local writes
from upward emission while preserving causal publication/version contracts.
Do not silently suppress existing memory/races to meet a convenient budget.

## Task identifiability before training

The controlled scene has eight recurring four-event motifs and seven binary
arrangement decisions in a depth-three binary tree. The label is parity of
those decisions: all hierarchy levels matter, a complete single child plus root
orientation is label-balanced, and relation swapping flips the target while
preserving time/polarity/count summaries. Each motif is identifiable by shape;
no identity enters model input. This is a deliberately demanding diagnostic,
not natural vision or a public benchmark.

TRAIN child-code XOR differences are {0,1,3,7}, spanning all three relation bits;
DEV {2,6}, TEST {4,5}. Each split has both difference parities, both root
orientations, every child code and balanced labels. No entire relation dimension
is fixed in training. Every test part is seen, every test combination is unseen,
and nuisance tapes are split-disjoint. The affine span avoids a particular
unidentifiability defect; it does not guarantee a unique generalizing rule among
arbitrary functions. Audit metadata is never fed to the learner. Future training
uses whole-scene labels only; internal part supervision would be a different,
explicitly disclosed protocol. Calibration must be TRAIN-only and frozen.
