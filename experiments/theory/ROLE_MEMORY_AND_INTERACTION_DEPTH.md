# Composition needs role binding and interaction order

15 October 2026. New native construction and a paired development comparison.

## What the completed evidence selects

World-relative indexing repairs the measured translation defect. Two short
whole-label fits still fail unseen combinations. A frozen full affine head also
fails, so another classifier scale or unchanged layer-count sweep is not the
next experiment. The next question is whether parents have an effective path
for combining particular children in particular roles, and whether learning
actually exposes a relation signal rather than class-frequency noise.

The native core already has nonlinear gates and hard races. Its input projection
receives child content v and pose r additively, W_v v + W_r r. In the restricted
additive-pooling path, summing over children loses which value occupied which
role: swapping v_a,v_b while retaining the role multiset leaves that sum fixed.
This is a diagnosis of that path, not an impossibility theorem for the native
core. Its nonlinear routing can learn interactions, but we should provide a
well-conditioned explicit compositional path rather than rely on it emerging
accidentally through many serial operations.

## Native role memory, not a message log

Each parent retains the latest published child view per (source abstraction
level,geometric quadrant), with its receipt time. Separate source levels avoid
conflating a pixel-region view and an already composed concept. The original
native core still consumes every accepted message; the role cache supplements
its existing persistent state. Indexed lower memories remain available. Role
cache views are private and never expose a producer's unpublished future state.

On a new child receipt, align stored views to the parent's local admission time
using its native protected/rotating/decaying transport. From normalized views
z_r form both role-conditioned terms A_r L z_r and ordered pair terms
B_ab[(L z_a) elementwise (R z_b)]. L and R differ at initialization; a symmetric
product alone would lose order. Unoccupied role/pair maps are not evaluated.
The resulting local vector enriches the current incoming value before the
unchanged native temporal core consumes it. Native keys/values, receipt races,
selected memory writes, local counterfactual teacher, publication semantics and
race-generated emissions remain. No new attention layer or auxiliary part ID
is introduced. Pixel-native objects receive no redundant role module.

Role-conditioned/bilinear feature maps are known primitives. The contribution
under test is their integration into persistent, time-evolving native parent
memory with explicit activity and learning costs. The default keeps all32value
channels, seven parent modules, four roles and six possible pairs per source
level. Ownership remains geometric; role slots are not learned object discovery.
General nonadjacent queries still enter native memory, while this auxiliary
cache keeps only the latest view per quadrant/source level.

## Interaction order is a distinct depth axis

For independent child arguments, affine sums do not create cross-child products.
A bilinear composition creates a degree-two interaction in its input features;
recursive nonzero bilinear compositions can multiply interaction order through
the tree. With bounded sign states [s,1], a hand-set two-channel composition can
map ([a,1],[b,1]) to [ab,1]. Three composition levels therefore express an
eight-way product with live derivatives to every input. The numerical contract
checks all256sign combinations. It is an expressiveness/gradient witness, not a
learned hierarchy result or a depth lower bound against arbitrary flat networks.
The actual native model also normalizes, transports and routes values; a global
polynomial-degree claim is not made for it.

A stack of zero-gated new operators would destroy the very high-order path we
want to train: the top interaction coefficient is a product of gates, with zero
first derivatives when several are zero. We initialize role/pair operators
nonzero and variance-scaled instead. Thus this is an explicitly changed function,
not prediction-preserving growth. The baseline has no successful task-quality
result to preserve. Native parameters are migrated exactly; added operators are
charged. The initial/final fixed-data comparison determines utility.

## Pair the learning signal without hidden supervision

The prior single-scene updates have large loss excursions and a drifting class
bias. For two opposite-label examples at equal logit0, the paired bias gradient
is exactly zero; the classifier-weight gradient is proportional to their feature
difference. This removes label-count noise from every step but cannot conjure
missing interactions. Common-random coupling preserves each example's race law;
its variance effect depends on covariance and is not assumed to be beneficial.

Pairs are derived from TRAIN sensor arrays and existing whole labels only.
Split observed x coordinates at the bounding midpoint, exchange the two halves
by their observed mean separation, and require that the exact transformed stream
already exists in TRAIN with the opposite supplied label. No hidden tree codes,
part IDs, generated new label or DEV input enters pairing. All128TRAIN scenes
form64pairs. The same public-input pairing applies to both native arms.

## Decisive comparison and boundaries

Compare FrameNativeComposition and RelationalFrameComposition with the same
acquired gesture core/fresh2-class head,64paired AdamW updates/128presentations,
order,common-race coupling and TRAIN/DEV splits. Backprop each half separately,
then update once, avoiding retention of two full graphs. Exact checkpoints retain
model,optimizer,order/global-race RNG. No external model is fitted. Score before
any DEV selection. Fixed TRAIN-only ridge.01 native affine readout is the primary
endpoint; jointly trained/scalar-calibrated heads remain diagnostics. Both heads
are the existing binary affine architecture, not an added decoder network.

Initial/final features are cached. If DEV beats the constant prior, test zero
emitted content with the fitted head frozen and cluster paired uncertainty by
child combination. TEST stays unscored. Count native candidate/selected/losing
work, role projection MAdds, products, transported views, parameter/optimizer
work, role cache bytes, messages and native state separately. No iso-compute,
energy or latency claim follows from equal presentations.

The current spatial supports are isotropic dyadic cells. Learned parts may need
anisotropic or overlapping supports and multiple concepts per region; a new
role operator does not establish that capability. A failed paired control versus
operator comparison selects support/binding/credit analysis, not an unchanged
larger fit. Start with one real-size paired resource/gradient gate before either
fit; preserve current source-bound jobs and native benchmark evidence.
