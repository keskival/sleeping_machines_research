## The construction

Each world pixel owns persistent native temporal memory. Input events update
that address causally using actual times/polarities. Pixel memories publish
locally; no initial2x2world-grid aggregation or eager upward emission is imposed.
After the revealed observation queue drains, establish the scene frame from
the minimum observed y and x pixel coordinates. This is an ordinary coordinate
transformation, not a learned or novel geometric primitive. It uses no labels,
part IDs, unseen inputs or future outcomes. No raw events are replayed.

At the first composition round, raw pixel memories arm native timers. The
emitted values retain native timing/state; source geometry is expressed relative
to the observed frame before parent assignment and relative-pose encoding.
Subsequent levels use that canonical grid. Existing native receipt races,
separate keys/values, persistent numerical state, local counterfactual teacher,
pure emission-timer credit and32native stages remain. Parameter keys/shapes and
acquired weights are unchanged. Indexed pixel memory stays world-addressed;
upper state is scene-relative. The frame origin is retained explicitly.

This avoids the first-event-anchor trap: choosing a different earliest event
would otherwise shift the frame under timing/order nuisance. Bounding coordinates
are computed from the already revealed pixel memories at composition time, not
from the first event or from a future scene. The current scene classifier already
waits for composition; no per-event forecast is reported.

## Exact translation contract

Translate all observed world pixels by a fixed vector d, retaining content,
times and order. World leaf memories are isomorphic under address+d. Their
native numerical updates match under the common race tape. The observed minimum
also shifts by d, so canonical coordinates are exactly unchanged. Sorting child
addresses preserves order under translation; parent ownership, pose headers,
clock sampling order and upper native computations therefore match. The output,
publication times and work counts match bitwise in numerical contracts.

This is an implementation equivariance contract for pure translation. It does
not assert invariance to timing, rotations, multiple object segmentation or
changes in the revealed support. Pixel-level persistence uses extra active
objects versus2x2leaf pooling, so its resource cost must be measured. Frame
comparisons/subtractions and world-pixel state are reported, not treated as free.

The frame is committed once per independent scene and never silently reindexes
existing upper states. Later observations use that fixed frame; observations
outside the root's128pixel support need an explicit different root/larger extent.
Dynamic moving-object frames and fully local streaming emission/ownership remain
engineering work. The phase barriers are a reference-executor restriction.
