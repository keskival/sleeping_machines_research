# Attribute native composition across value and timing channels

15 October 2026. Endpoint amendment made while both paired native fits are still
running, before their completed DEV results. No actor/training change; fixed
primary TRAIN-head/DEV protocol is unchanged.

A persistent child can communicate through its emitted value, emission timing,
address and availability/silence. Removing only values cannot establish absence
of useful native composition: timing and availability can carry what the parent
needs. Preserve and report a positive prediction result with its actual scope.
Attribution is a separate question from whether quality improved.

For each arm whose final materialized native head beats the balanced DEV prior,
run three frozen interventions under the same race tape:

- Zero upward emitted values; retain sensor processing,addresses and clocks.
- Fix each lower object's arm-to-emit interval to .011, the upper bound of the
  native pure timer transform. Compute/sample the original timer to preserve
  random-draw consumption, then schedule the view at this fixed later time.
- Apply both cuts together.

The delay cut stays causal: the object is published before arming, its original
bounded due time is no later than .011, and the indexed view is read at the new
later time. It changes scheduling and value transport jointly. It is an
intervention on the timing mechanism, not a clean separation of all information
encoded in time. Native internal computation clocks and group readiness remain;
the root's final readout timer is retained. Addresses/availability remain in all
cuts. These restricted executions are diagnostics, not the flagship policy.

Use observed-geometry clusters to report paired loss changes, avoiding hidden
generator IDs in fitting,selection or uncertainty grouping. A positive interval
for a cut supports use of that mechanism. Joint cuts can reveal synergy where
single-channel cuts do not. Positive transfer without an attributed value/delay
benefit is still reported as positive prediction; investigate address/availability
and internal timing before semantic promotion. Do not relabel it a family loss.

Qualified development candidates require positive clustered benefit over the
prior and benefit from at least one of these value/timing interventions. This
extends the earlier value-only attribution plan to the actual native channel
set before results are known. One reused synthetic DEV set/seed is not sealed
confirmation; fresh compositional confirmation and semantic probes follow any
candidate. No additional fitting or TEST model scoring is admitted by this note.
