# Compose complete parts before composing relations

16 October2026. Measured support failure and native repair;no class-transfer
result is inferred.

The prior dyadic native supports are not neutral. Anonymous spatial components
were inferred using a threshold selected from TRAIN geometry:for each TRAIN
scene,find the largest adjacent edge-length ratio in its spatial minimum
spanning tree;take the median geometric midpoint of those gaps. The fitted
threshold is10.723805pixels. It finds8components in each of128TRAIN and64DEV
scenes without accessing latent identities,arrangement codes,class labels or
TEST. These are observed spatial groups,not certified semantic objects.

**25% of these groups never have a pure complete native support**,on both TRAIN
and DEV. They remain fragmented until a cell also contains another group.
Whole-part identity learning was therefore being asked to operate through
incomplete or already mixed representations. More depth,geometry reconstruction
or larger gradients cannot make that missing intermediate object appear by
itself. Versioned directories recover access,but do not change ownership.

`ObservedOwnershipComposition` assigns each observed group to one level-one
native memory before upper composition. All world-pixel native memories remain.
Their race-generated views enter the group's common native receiver,with
observed intrinsic coordinates. The group has a distinct addressed memory at
its observed centre;subsequent levels retain native spatial/time composition.
Eight abstraction levels,four native stages each,hard races,keys/values,
selected state writes,counterfactual credit and timer-generated views remain.
There is no added actor parameter or hidden symbolic part identity.

A full32event TRAIN gate gives **eight pure complete part memories,each with
four observed pixels**,and nonzero finite content gradients through all eight
levels. Actor training/evaluation forwards match bit-for-bit under one race
tape. This is not equality with the old actor:the intended information path
has changed. Existing acquired weights are reused;no optimizer fit or class
score is used to declare success.

The receipt records3328native candidate scores,3328counterfactual value
evaluations,1664selected updates,104deliveries,146timer scores and496ownership
pair-distance tests on the scene. These are separate partial work counts,
not complete fitting FLOPs or a comparable-quality efficiency win. The gate's
563828KiB process peak and3.3569s cover one learning traversal plus a separate
no-gradient forward,not the earlier two-actor versioning gate's boundary.

This candidate is explicitly a **static revealed-scene** grouping policy.
Its threshold is fitted on TRAIN;relative part frames use only currently
revealed geometry. New pixel support after ownership is established requires
an explicit revision policy and is rejected. It does not solve moving-object
tracking,overlapping semantic objects,learned ownership or streaming merges.
Those require persistent ownership proposals,versioned merge/split operations
and competition between explanations. The versioned directory supplies a
useful foundation:old wholes can retain their bound parts while ownership is
revised,rather than being silently rewritten.

The next semantic experiment must distinguish the benefits of complete parts,
learned stable identities and nonlinear role composition. First inspect
identity stability and relation sensitivity in the corrected part memories;
then admit a matched continuation against the acquired frozen actor. Do not
replace learned representations with component IDs or count a support repair
as class transfer.
