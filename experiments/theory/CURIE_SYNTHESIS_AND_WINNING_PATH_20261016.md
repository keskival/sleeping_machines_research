## What composes

Use two channels: an event says when and where computation is warranted; a persistent addressed memory stores the content that can be refined and queried later. Curie's attribution stream changes identity on 78.59% of tokens (mean duration 1.27). Treating each identity change as a semantic abstraction would confuse a routing decision with a durable concept. Queryable immutable versions in the AWS native learner and additive addressed refinements in Curie's RMR are compatible approaches to the missing content channel.

For a slot with shared linear temporal transport D, M(t)=sum_k M_k(t) and D(sum_k M_k)=sum_k D(M_k). A sparse higher-level write can therefore refine an older slot without synchronizing every level's cadence. A direct readout from the total memory supplies a direct derivative to each contribution, alongside indirect derivatives through later readers. This is the strongest constructive case for depth currently available.

Three distinctions are essential. An additive contribution can cancel a lower contribution numerically; retaining the lower component separately preserves recoverability, not immunity from interference. An identity derivative at memory addition does not bound the derivative through the readout or protect against saturation. Nesting the shallower family via zero corrections proves attainable optimum containment, not monotonic SGD progress or generalization. ReZero gates and bounded old-slot updates address measured instability; learned abstraction remains an empirical objective.
