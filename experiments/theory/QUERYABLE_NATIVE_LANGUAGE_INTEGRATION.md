## Failure addressed and retained construction

The current language core transforms the current lower message and its own receiver state. Its prediction head recalls old depth views, but higher receivers cannot themselves query and jointly compose lower publications. This omits interfaces already implemented in the native hierarchy. Reuse its BindingStore/BoundSnapshot/PartBinding and ChildRoleComposer rather than another unrelated backbone.

`QueryableLocalDeepRace` extends the reference native local learner. Each layer publishes immutable numerical receiver-write versions, their incoming values, native head times, selected receiver identities and own-write eligibility. A publication address is the tuple of native receiver winners, not a semantic identity claim. Each upper layer races over a declared ring of lower publications, reads up to two distinct versions without replacement, and places their responses in two explicit query roles. The existing nonzero role-conditioned/bilinear composer enriches the upper incoming message before its unchanged native receiver races. Query slots are binding roles, not invented spatial quadrants. Different versions can refer to the same instance; two selections are not proof of two semantic parts.

Queries score separate keys; only winner and one sampled losing value per role are decoded. Original publication availability and head clocks are retained. Responses have independent positive race delays and native alignment before joint composition; the next layer waits for their availability. Input token time remains chronological and all dependencies travel upwards. This numerical reference still executes every layer/token. Learned emission suppression, sparse publication discovery and autonomous timer scheduling are not integrated.

## Credit and version semantics

A historical read decodes its saved numerical receiver state with current local output maps and transports it from original head time. At unchanged parameters and original availability it must match the original layer output including its saved residual. Its numerical receiver value, residual, input and key do not change after publication. Parameter changes may change the decoded view, just as a learned read map can change; immutable state does not mean a forever-frozen decoder.

The read's memory cotangent is projected into that publication's own-write eligibility through the existing receiver credit machinery. This supplies an explicit path from a later upper-layer loss to an earlier lower receiver write, without a recurrent graph. It does not recover full derivative through earlier incoming producers, hard route changes or parameter updates. Routing uses the existing local linearized counterfactual surrogate, not an exact gradient of the sampled nonlinear expected loss. Synchronous AdamW/global clipping remain. Stored traces are immutable snapshots, not the live receiver's subsequently updated trace.
