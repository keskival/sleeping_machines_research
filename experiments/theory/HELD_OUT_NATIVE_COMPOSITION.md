# Next gate: learned parts must survive unfamiliar combinations

15 October 2026. Design, not admitted training or completed evidence.

The completed native FIT result establishes a useful input-conditioned signal.
It cannot distinguish instance memorization, local texture and reusable parts.
The next experiment must separate these explanations before a larger gesture fit.

## What will count as representational hierarchy

A level must integrate multiple independently varying lower parts, preserve
relative arrangement where the task needs it, and expose a reusable state whose
meaning survives a new parent combination. More serial race operations, broader
spatial support or slower clocks alone do not satisfy this test.

Use a controlled event-camera-style generator with nested local motifs, parts
and wholes. Local motifs recur across classes. Label depends on ordered relative
part arrangement; class-conditional event counts, polarity totals, absolute pose
and timing nuisance distributions must match. Every constituent occurs in
training; withhold specific combinations and nuisance realizations, not an
entire unseen constituent. Include a second split withholding whole motif
instances to separate combination transfer from exact part matching. This is
our own capability benchmark, not a public vision benchmark.

Before admitting fitting, implement and hash a split manifest and check: no
identical streams across splits, balanced nuisance summaries, every test part
supported in training, held-out combinations absent from training, label change
under the designed relation swap, and an anonymous-input-only scoring path.
The generator's internal part identities may audit splits but must not enter
model messages, routing, fitting targets or model selection. Sensor geometry and
causal event times are allowed. Prefix-only views must be checked for sufficient
label evidence; do not impose 32 events merely because the earlier driver did.

## Strong native fighter and causal protocol

Use VarianceReducedNativeComposition: eight abstraction levels/four native
stages, persistent addressed state, separate keys/values, native receipt/value
races and their local counterfactual teacher, memory reads and pure emission
timers. Start from acquired weights when input semantics match; preserve an
initialization reference. Reuse frozen logits and models before more fitting.
No raw event shortcut is added to the terminal read round. Current exhaustive
active-memory queries are charged and disclosed; sparse learned query selection,
learned object ownership and global queue-order credit remain absent.

The controlled generator is stationary. Fit only TRAIN; freeze weights, prior,
centres and gain before DEV or TEST scoring. Reset state between independently
generated scenes because each scene has no preceding causal history; retain
numerical state throughout every scene, independently of gradient truncation.
This does not replace the online/persistent-state protocol required for real
non-stationary streams. Keep common stochastic tapes across paired interventions
and never use a per-example noise seed as an identifier. Select on DEV, score
sealed TEST once after the improvement plan is complete.

## Decisions, interventions and cost

Compare native full memory, zero query contents and relative-pose removal under
frozen training calibration. Separately intervene at lower, middle and upper
learned states. Check whether the predicted constituent/relation information is
recoverable at the appropriate level on held-out combinations; any auxiliary
probe is fitted on TRAIN only and its cost is reported. Dependence on an
intermediate state does not alone prove it is a semantic part representation.

A credible composition advance requires held-out quality above its training-only
constant prior, a paired interval excluding zero benefit from lower-memory
contents, and sensitivity to the task's arrangement-changing intervention.
Report seen and held-out combinations separately. If only seen combinations
improve, repair constituent/pose binding or the credit path diagnosed by the
interventions; do not launch an unchanged depth grid. Only after this gate should
we test whether added abstraction levels improve useful compositional capacity.

Before any queue admission, measure a bounded real-size forward/backward, host
memory and existing job occupancy through the authorized coordinator. Declare
operation counts, state bytes, message traffic, counterfactual work, complete
fitting and inference arithmetic when audited, and protocol restrictions.
The gate changes whether to scale learned composition or repair binding/credit.
No job is admitted by this design note; the generator and admission checks are
required implementation work.
