# Local writes and upward emission are different operations

15 October 2026. Repair selected by a measured memory failure.

The eager adjacent-frontier gate was stopped after 20 seconds by the RSS
watchdog at 3,202,220 KiB against the 3,000,000 KiB slot limit. No task quality
or completed comparative work result was produced. Do not widen the shared-host
limit or reduce representational depth to conceal the publication problem.

`CoalescedNativeComposition` keeps every raw receipt and its native memory
update. A local publication exposes an indexed state, but does not automatically
send another message upwards. In an explicit composition round, all active
children at one level arm native pure timers at the same current virtual time.
Their races generate evolved views; views arrive chronologically and update
persistent parent memory through the native receipt/value races. After that
round drains, the next level arms. The root generates its own timed readout.
No raw-input bypass, feature encoder, external supervision or extra parameters
are introduced. Indexed reads/queries and explicit future arming remain usable.
Only the default automatic write-to-upward-message coupling changes.

For N observations and n_l active memories below the root, receipt count is
N + sum_l n_l for one composition round. This replaces eager per-write cascades
and their repeated frontier cascades. It does not make key scoring, losing-value
credit, transport, timers or state free; the native operation ledger charges them.
One view can summarize many receipts. Whether that summary preserves task-useful
relations is a learned capability question, not a consequence of compression.

This policy deliberately removes intermediate upward views and may lose useful
fine-scale change signals. Local native memories still receive the actual
asynchronous input times, and their readouts evolve at elapsed-time-dependent
native clocks. Neither global completion barriers nor arming are learned.
A future streaming policy must emit on causal local conditions or budgets rather
than wait for a whole scene, and must account for missed changes and learning
through event-order boundaries. The current construction is a bounded capability
candidate; it does not replace a better task-suitable continuous-stream model.

All value-routing races retain the original coupled teacher. Pure-timer
winner-averaged credit applies to the interior timing derivative only; sorting
or stale-version boundary changes need separate credit. Train/evaluation
stochastic forward parity, full eight-level gradient support and finite drainage
are numerical contracts. A new source-bound no-fit gate reuses acquired weights,
measures the identical TRAIN scene and changes the decision about admitting
composition learning. No old 11-class output is treated as a two-class task score.
