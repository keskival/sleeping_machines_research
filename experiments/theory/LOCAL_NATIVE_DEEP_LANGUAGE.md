# Beat the dense hybrid with deep native computation and local learning

16 October 2026. Founder priority: first beat the saved dense hybrid with a completely native deep model, exploiting the family's advantages in both prediction and learning. No new dense model is trained. CERL's existing SSM-backed fit remains a cause-head development diagnostic; it is not the complete native construction requested here.

## Failure and construction

The old native deep stack fed its last stage back into the next token's first stage. Its temporal credit path multiplied sequence length by depth, and deeper fitting failed. The dense replacement made depth easier but removed the native substrate. The replacement here repairs native composition: each of eight layers owns persistent addressed receiver memories and consumes messages from the layer below. A token's top output never feeds the next token's bottom input. Separate keys and values, independent exponential head races, real-valued computational delays, complex temporal transport, sparse winner writes and sampled losing-route credit remain active.

All eight layers provide causes to an exactly normalized depth race. Within a depth, the reused CERL cause law races episodic repeat/continue pointers, product-key-selected dormant concepts and a two-stage background word law. The reused head is constructed with **zero SSM/MLP backbone layers**. Every predictive state is produced by native receivers. Local embeddings, normalizations and projections support those computations. They do not form an alternative carrier.

Each layer consumes detached lower messages. Its own race/posterior responsibility supplies its task cotangent directly, rather than requiring error to traverse every lower layer. Its persistent receivers integrate many lower messages over time. A direct local task loss is a proposed useful teacher, not proof that higher layers acquire better abstractions. The composition experiments establish why increasing response magnitude alone is insufficient; binding and joint-relation acquisition must be measured.

## Receiver-local credit instead of recurrent BPTT

For complex receiver mode j, conditional on an incoming message x and selected receiver:

    z'_j = a_j z_j + w b_j,
    a_j = exp[(-r_j f + i omega_j) elapsed],
    f = softplus(control_forget(LN(x))) / log(2),
    w = 2 sigmoid(control_write(LN(x))), b = complex(input(x)).

An own-parameter eligibility obeys E'_theta = a E_theta + (partial_theta a) z + partial_theta(w b). Because each memory mode depends only on its own complex pair, the input-map derivatives can be factored by pair and input coordinate. Shared control derivatives are stored per pair, then summed when a local read cotangent arrives. This costs O(P²) trace storage per occupied receiver, independent of event count, rather than retaining an unrolled temporal graph. Dormant receivers are not advanced between their addressed events. Proposal traces are immutable; only the actual winner's state is committed.

`native_receiver_eligibility.py` implements the actual TemporalUnit write, including its input-dependent forgetting/writing controls, raw rates and rotations. Fixed-parameter contracts at 1/7/41 events match the native unrolled reference in float64 within 2e-11, including zero gaps. The reference unroll is a numerical test oracle; it is not the learning algorithm. Delayed cotangents can credit earlier writes through the trace without replaying those events.

Scope is essential: exactness is conditional on fixed input messages, routing choices, timestamps and parameters. This is not full-network RTRL. Route-choice credit remains the native local counterfactual surrogate. Cross-producer credit is supplied by local prediction interfaces, not an exact end-to-end derivative. When weights change, carried traces are an online local approximation; stale-parameter transport is not magically exact. Current-event maps and bounded episodic write graphs still cost memory/backward work. The optimizer is initially synchronous at a declared credit boundary; asynchronous/versioned receiver updates need a separate integration contract. Persistent numerical memories must survive that boundary.
