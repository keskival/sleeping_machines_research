# Native composition: the next competitive decision

17 October 2026. Battle R1. The objective is strong prediction from persistent,
queryable, race-composed representations with economical event-local learning.

The completed four-level residual-memory model improves flagship DEV NLL from
5.063392 to 5.043258 at 16M tokens; the independent longer slice improves from
5.028151 to 5.024371. It is a carrier-backed, current-slot composition result,
with old-slot rewrites disabled. It demonstrates useful composition in this
construction, not a fully event-local deep-learning win. Enlarging the concept
bank to 262144 units at 4M gives 5.471524 versus the saved 5.466546 base:
capacity alone is not the next decisive intervention.

## Selected avenue

Make useful multi-memory composition learn through its actual producers.
The queryable eight-layer native actor already has persistent versioned lower
memories, joint queries, separate keys and values, temporal races, counterfactual
alternatives, receiver eligibility and historical producer replay. The remaining
competitive question is whether its full-depth sampled child-content credit
improves prediction after adequate contiguous data. Its frozen-parameter
conditional pullback expectation passes the numerical contracts; changing
parameter staleness, gradient clipping and incomplete historical routing remain
explicit approximation boundaries. A correct derivative alone is not a win.

The saved joint-credit arm completed all 65536 extra TRAIN targets, including
its canonical frozen development evaluation. The driver then failed on the
first online DEV batch: its first input did not match the last revealed target
stored in persistent numerical state. Do not reset memory or refit that arm.

The repaired transition consumes the already revealed last TRAIN token to
forecast the first new DEV token. Each following DEV token is scored exactly
once, before it can affect weights used for that forecast. Subsequent batches
must match their revealed predecessor. This is an explicit artificial tape
splice, with the same policy in both arms, not natural document continuity.
The first forecast is included in the 8192-target prequential endpoint. The
canonical frozen windows are unchanged and reported separately.

Recovery copies the immutable old parent and completed joint-arm checkpoint
into a uniquely named run. It verifies each inherited loaded-source identity,
parent digest, complete training cursor, completed frozen evaluation, zero
online targets and prior exact-recovery certificate before restoring all actor
parameters, Adam moments, numerical state and RNGs. The previously unstarted
full-depth child-credit arm fits from the same original parent; it does not use
the better joint endpoint as privileged pretraining. No acquired evidence is
silently discarded. Both native arms adapt after each 32 scored targets.

## Action and decision

Slot 2 runs the persistent-transition contracts, then the recovered paired
comparison. The transition gate uses a real native model and verifies training
across the tape splice, unchanged historical memory, exact checkpoint recovery
and rejection of an inconsistent later predecessor. Existing source-bound
trainers in slots 3 and 4 finish unchanged. No external control is trained.

Report frozen and prequential NLL, novel-target and window differences, whole
and incremental process costs, all actual/audit presentations and the recorded
native operation counters. Full arithmetic/special-function/traffic accounting
is unfinished; no matched-work or hardware claim follows. Promote credit only
on completed predictive evidence. A flat result calls for diagnosis of actual
producer path use, variance/clipping and representation sufficiency, not a
larger blind capacity sweep.

The calibrated reciprocal-credit learner is a complementary prospective test.
Its neutral policy currently protects the service trajectory while separate
nonzero audits learn actual finite future effects. Do not promote it into the
main actor before it improves future prediction. Neither waiting for that
trial nor its possible failure blocks the composition-credit comparison.
