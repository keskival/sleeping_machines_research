# Native credit for unseen receiver addresses

Curie,10 October2026; B1/R1 shared enabler. Current real-market state-credit learners have not yet yielded a replicated quality/work advantage. The next question is whether a shared connected critic learns credit for inactive receiver addresses outside its counterfactual training pool. This is a bounded native-mechanism diagnostic before online integration or depth scaling.

## Native intervention and retained mechanisms

Use the existing depth-four keyed temporal TPP from future_route_critic_v1: deep decaying/rotating state, sparse addressed key/value writes, separate queries/keys/values and timed race likelihood. At a causal prefix after event3, an optional four-dimensional key message a may be delivered to one selected receiver r in0..7. Original factual writes and all future temporal/value dynamics remain; only the additional addressed key affects later mark race scores. The optional destination is a hard selected address. This does not establish general internal race routing or full actor weight learning: the actor stays frozen for this diagnosis and original factual write addresses are observed marks.

Known fixed-learning-path response algebra remains exact for this optional delivery, including inactive r. For each future target, beta=q^T decay*a/sqrt(d_key), b=1[target=r], p_c=base mark probability of r, and w_c=posterior clock weight given the observed target/gap. The loss difference is -b*beta-log(sum_c w_c/[1+p_c*(exp(beta)-1)]). Verify values and action derivatives against actual native destination writes before fitting. It does not certify counterfactuals that change hidden-state transitions or later online optimizer updates.

## Information and generalization split

A shared critic consumes the revealed30-dimensional forward prefix plus receiver-conditioned state (four keys), forecast mark probability, observed mark match/count and observable key/value role. There is no raw receiver identity input. Roles follow the benchmark's observed token alphabet; no future query identity or continuation outcome enters features. The connected encoder and bounded structured response decoder learn one function over descriptors; a nearly parameter-matched free critic uses the same encoder initialization. Known GRU/normalization primitives are supporting components, not a new architecture claim.

Fit only counterfactual receiver addresses0..5 and nine bounded basis messages per receiver. Never form TRAIN intervention labels for receivers6/7. Fresh DEV prefixes query all eight receivers and evaluate16 independent synthetic continuations per prefix. Measure held-out6/7 calibration, and separately the subset where r differs from the factual active address at the write event. Reference: zero/frozen predictors, TRAIN-mean best permitted0..5 action, and fixed-pool selection versus enlarged-pool selection. Outside-pool utility is actual native future-loss improvement, not predicted value. No label-dependent filtering of examples or routes.

A relabeling contract permutes value receivers, observed marks and the corresponding embedding, clock-slot columns and mark-output rows. Prefix descriptors and actual intervention effects must commute with that permutation. This demonstrates the implemented coordinate equivariance, not learned future utility or arbitrary unseen-function identification.
