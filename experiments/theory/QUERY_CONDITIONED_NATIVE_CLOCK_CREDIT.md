## Concrete failure and proposed substitution

The current addressed critic processes 32 typed mode receipts before selecting
four residual coordinates. Its 16-dimensional final representation serves 64
separate linear output rows. At 256 source receipts, each mode receives only
16 current-decision labels. Increasing the head gives different addresses
different parameters, but does not condition the representation on the issued
target. The completed selected-row compiler removes unused decoder arithmetic;
it leaves this native event-processing burden intact.

For issued mode m, replace the 64-row head by a shared four-leg head conditioned
on the two layer/mode receipts. Write

    h = F_psi(global_context, observed_feedback, query_0m, query_1m, memory)
    delta_(layer,leg,m) = (scale_(layer,leg)/4) * 0.5*tanh(H_psi(h)_(layer,leg)).

Other residual coordinates are zero. The retained parent and actor's own
gradients continue their existing updates. The support schedule, bounded chart
and paired finite-future teacher stay fixed. Every source receipt now teaches
the shared four-row head; this is parameter sharing, not a claim that every
target receives 256 independent labels or that a shared head must generalize.
Address identity and local theta/g/m/v distinguish targets; shared native
temporal functions can learn similarities in their consequences.

Retained mechanisms: temporal races, separate keys/values, hard addressed
private critic banks, persistent causal state, typed optimizer receipts,
counterfactual actual-learner supervision and retained parent. Removed input:
the 30 nonselected mode tokens at the current decision. Global actor context
and the global clipping coefficient remain available. Missing cross-mode
optimizer information can impose a real conditional-information floor; larger
shared capacity cannot repair an exact alias in the reduced input.

## Economy and its boundary

With one observed token, the added native branch processes four events per
decision (context, observation, two queries), rather than 34. The parent still
processes two: total native events become six rather than 36. Applying the
existing eight key scores/four selected writes per event gives 48/24 versus
288/144 respectively. These are structural counts, not measured traffic,
whole-fit FLOPs, energy or ASIC latency. The head returns four values instead
of 64; availability remains 64 and selected residual activity remains four.

`native_query_clock_credit.py` deliberately reuses the immutable receipt helper
and filters its output, so all-mode Adam-response and token construction is
still paid. A later selected-token implementation must retain the global norm
reduction and pass token parity before charging reduced preprocessing. Actor
own-gradient work, Adam, teacher worlds, private history, and parent acquisition
are additional. The construction introduces no dense recurrent critic or
global event barrier; existing actor Adam still has a global norm contraction.
