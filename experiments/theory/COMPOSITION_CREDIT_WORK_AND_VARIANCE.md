# Composition credit: total work, variance and event rates

16 October 2026. Supplement to COMPOSITION_CREDIT_ANALYTICAL_AUDIT; feeds the admitted R1 paired continuation and its next credit-allocation decision.

The sampled producer estimator takes at most d extra reads for a root at zero-based memory level d. This is linear **per root**, not a proof of linear total training work in network depth. With R_d root reads at level d, the extra work is bounded by sum_d R_d*d. In the current native construction every upper level k=1..D-1 queries two memories from level k-1, so the extra replay bound is 2*sum(d=0..D-2)d=(D-1)(D-2). At eight levels this is42 additional reads per input, plus14 factual selected root reads:56 together, before discovery, alternatives and all other learning work. The generic API's depth-1 per-root cap also supports reading a top-level memory directly; it is not the number charged to every internal root. Available lineage can shorten realized paths. Count actual replay edges rather than multiplying the generic cap by every query.

Independent event rates can change this substantially. If roots at depth d are activated at rate rho_d relative to inputs, expected replay work is proportional to sum_d rho_d*d. A geometric activity envelope rho_d<=C*r^d with r<1 makes this series bounded as maximum depth grows, since sum_d d*r^d=r/(1-r)^2. This is a conditional cost result, not a measured property of current language learners. The native reference currently executes every level per token. RMR2's soft expected firing still evaluates its branches; firing probabilities alone do not prove dispatch savings.

Unbiasedness also does not mean useful variance. For a vector sum V=sum_r v_r and one sampled branch with probability p_r, the second moment of the unbiased estimator is sum_r ||v_r||^2/p_r. The minimum over proposals is reached at p_r proportional to ||v_r|| when those norms are available. Uniform binary sampling can multiply inverse-inclusion weights by up to2^d. Whether credit variance explodes depends on the actual Jacobian products and alignment/cancellation of branch contributions, not just path length. A uniform proposal gives a clean first implementation, not a low-variance scaling guarantee.

A promising next native credit engine is **cotangent-directed deferred replay**. Once an outcome has been scored and the local composer has received its task cotangent, compute its two child-view cotangents locally. Sample which historical child producer to replay using a positive-support proposal informed by these cotangents, then divide by the actual inclusion probability. This selects learning work after the observed outcome; it does not alter the already issued forecast. It needs no dense forward activation stream and can emit local credit packets asynchronously. Child-view cotangent norms are a cheap proxy for complete child parameter-credit norms, so they do not by themselves attain the global minimum-variance proposal. A learned future-response model must retain residual corrections and positive support if exact conditional expectation is claimed.

This should be implemented if the admitted uniform-path comparison shows excessive preclip norms/clipping or poor quality/work. The current comparison records raw gradient norms, clipping multipliers, actual replay edges, candidate/selected/alternative activity, persistent storage and both frozen and causal-online prediction. It does not impose extra regularization or erase persistent state to hide credit variance. The first question is empirical: does reaching the lower producers improve learning enough to justify the measured additional work?

Replay work and provenance storage are also different budgets. The current binding store retains the transitive closure of immutable child versions. For binary branching and r root versions per level, a no-sharing upper bound over D levels is r*sum(d=0..D-1)(2^(d+1)-1)=r*(2^(D+1)-D-2), also bounded by the number of versions actually produced. Shared substructures can make actual storage far smaller, as measured in the eight-level implementation, but a root-ring cap alone does not prove bounded storage independent of depth or stream duration. A sampled reverse path bounds current learning work, not this retained closure. Credit-store compaction, reusable numerical eligibility and addressed memory tiering are explicit scaling engineering obligations; silently deleting persistent semantic state to satisfy a credit budget would violate the architecture contract.

Finally, sparse selected writes do not make the current global optimizer sparse. Dense parameter gradients, Adam moments/updates and weight decay can touch large dormant banks even when only a few values are delivered. The completed 65,536-unit capacity point establishes available slots versus selected concepts and prediction quality; its saved main-loss operator subtotal omits auxiliary backward and optimizer work. It is not proof of flat total learning cost with capacity. Bank-local learning/optimizer execution and full traffic accounting remain concrete implementation work rather than assumed hardware savings.
