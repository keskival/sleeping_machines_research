Author: AWS session, user direction "depth must scale; learn hierarchical representations of asynchronous data".
Status: design plus implementation (`experiments/r1_async_hierarchy_lm.py`), queued after plan B
(`experiments/r1_deep_keyed_lm.py`) and the race-core ladder (Curie). Nothing here is a measured result yet.

## 0. What a hierarchical representation of asynchronous events is

Let E⁰ = {(t_i, k_i, x_i)} be a marked event stream on [0, T): times t_i, discrete marks k_i, optional content x_i, with
history filtration F⁰_t generated by the events before t. A **hierarchical representation of depth L** is a family of
derived event streams E¹, …, E^L and level states S¹_t, …, S^L_t such that, for every level l ≥ 1:

- **(H1) Causal emission (asynchrony).** Each event time τ^l_j of E^l is a stopping time of the level below's
  filtration F^{l−1}, and each event's content is F^{l−1}_{τ^l_j}-measurable. A level acts only when the level below
  has given it reason to, at its own times, with no shared clock. S^l_t is a function of E^l up to t and the elapsed
  time since its last event (it keeps evolving through silence).
- **(H2) Nesting (compositionality).** Every level-l event closes a segment of level-(l−1) events: the interval
  (τ^l_{j−1}, τ^l_j] is a union of consecutive level-(l−1) segments, so τ^l ⊂ τ^{l−1} as sets of times. The
  segments form a forest whose leaves are base events. The content of a level-l event summarizes its segment.
- **(H3) Coarsening (time-scale separation).** The level's event rate satisfies E[N^l(T)] ≤ ρ_l E[N^{l−1}(T)] with
  ρ_l < 1, so mean inter-event gaps grow geometrically with level.
- **(H4) Predictive abstraction.** Higher levels carry the information about the longer future. With
  I_h(X) = I(future of E⁰ on [t + h, ∞) ; X) the predictive information about the future beyond horizon h,
  the share of I_h(S^1_t, …, S^L_t) recoverable from the top levels S^{l..L}_t increases with h, and the lower levels
  add mainly short-horizon detail: I_h(S^{1..L}_t) − I_h(S^{l..L}_t) → 0 as h grows past the level-l time scale.

A representation that satisfies H1–H3 but not H4 is a segmentation without abstraction; one that satisfies H4 at
every token step without H1–H3 is a deep but synchronous representation. The family's target is all four.

**Measurable versions.** H1 and H2 hold by construction (emission at level l is allowed only where level l−1 emits,
using only past information; causality contract). H3: emission rate per level. H4: horizon-resolved ablation, i.e. the
increase in loss at prediction horizons h when level l's state is replaced by its unconditional mean, which should
grow with h for upper levels and shrink for lower ones. **External validity**, where ground-truth structure exists:
FAS (event → step → item → line), language (token → word → sentence → document): boundary alignment of level-l
emissions with the true segment ends (precision/recall against base rate), increasing in coarseness with l.

## 1. Why depth has not paid so far (measured)

| Failure | Evidence |
|---|---|
| Hard routes chain: every stage forwards only the winning receiver's value | content cut at any of 16 P24 stages costs the same 1.5595 nats; D2 6.160 → D8 6.290 → D16 6.372 at 8M |
| Credit horizon: 16-token state-gradient window | stacking stages adds no long-range memory (theory/CREDIT_HORIZON_AND_ADDRESSED_MEMORY.md); history beyond 64 tokens worth 0.004–0.008 nats |
| Route collapse and weak deep credit | D16 route entropy 0.33 of 1.39 nats; deep receiver gradients ~1e-5 |
| Residual alone is not enough in the race core | residual D8 7.103 vs D2 7.081 (1M, seed 6); D16 residual + reads diverged (7.906 → 8.398 at steps 512 → 1024, gradient spikes) |
| Every layer runs at the token rate | no pressure for upper layers to represent slower, more abstract structure |

Two formal facts organize the remedies.

**(F1) Path support.** If each of D stages routes hard with per-stage probability p of keeping a given content
component on the path to the output, the component survives with p^D. Residual addition keeps an identity path of
probability one, so the output is a sum over 2^D paths whose shortest member always exists (Veit et al. 2016: residual
networks behave like ensembles of shallow paths). Any depth construction must keep an always-present identity path and
make routing additive (route-weighted contributions into a residual stream), never substitutive.

**(F2) Credit path length.** With end-only supervision, the gradient reaching layer l passes through D−l blocks and
through the temporal recurrence inside each; its variance and bias grow with both. A local objective at every layer
gives each layer an O(1) credit path (deep supervision, Lee et al. 2015; greedy and decoupled layerwise learning,
Belilovsky et al. 2019/2020; local error signals, Nøkland & Eidnes 2019); predictive-coding hierarchies reproduce
backpropagation's updates under small-error assumptions (Whittington & Bogacz 2017; Millidge et al. 2020) while every
update stays local. Local learning is also our hardware advantage: no global backward pass, no global clock.

## 2. What deep event-driven and recurrent networks do (sources)

- Residual identity paths with branch scaling: ResNet (He et al. 2016), Fixup (Zhang et al. 2019), ReZero (Bachlechner
  et al. 2020), DeepNet/DeepNorm 1000-layer Transformers (Wang et al. 2022), depth-muP 1/sqrt(L) branch scaling
  (Yang et al. 2023). Deep spiking networks reached 100+ layers only with spike-element-wise residuals (SEW-ResNet,
  Fang et al. 2021) and threshold-dependent normalization (tdBN, Zheng et al. 2021).
- Stable deep recurrences: diagonal state-space layers stacked tens deep (S4, Gu et al. 2021; S5, Smith et al. 2022;
  LRU, Orvieto et al. 2023; Mamba, Gu & Dao 2023) rely on eigenvalues initialized near the unit circle, per-layer
  normalization and input normalization (LRU's gamma). Our temporal memory layers are members of this class.
- Multirate hierarchies: Clockwork RNN (Koutnik et al. 2014) fixes slower periods per module; Hierarchical Multiscale
  RNN (Chung, Ahn & Bengio 2017) learns boundary detectors so upper layers update only at learned segment ends and
  discover word-like units unsupervised; Phased LSTM (Neil et al. 2016) gates updates by learned oscillation phases
  for event-based sensors; Hourglass Transformers (Nawrot et al. 2022) and MEGABYTE (Yu et al. 2023) shorten upper
  levels by pooling.
- Asynchronous deep networks on events: asynchronous sparse convolutions (Messikommer et al. 2020) and asynchronous
  event graph networks (AEGNN, Schaefer et al. 2022) update only the nodes an event reaches, layer by layer, so compute
  follows activity through depth.
- Continuous-time models for irregular data: ODE-RNN (Rubanova et al. 2019), Neural CDEs (Kidger et al. 2020),
  liquid / closed-form continuous-time cells (Hasani et al. 2021/2022): state evolves between events, as ours does.

## 3. Plan C construction: the asynchronous multirate race hierarchy

Each level l = 1..L is an event-driven temporal-memory layer with its own clocks, receiving events from the level
below and emitting events upward.

1. **Residual identity path and additive routing (F1).** Every level writes into a residual stream through a gate
   initialized at zero (ReZero/Fixup), so at initialization the hierarchy computes exactly the base model; depth can
   only add. Sparse race routing, when used, adds route-weighted contributions to the stream.
2. **Race-gated upward emission (multirate asynchrony; H1–H3).** Level l keeps an emission clock that may fire only at
   level-(l−1) event times (nesting); when it fires, level l sends one event upward carrying a summary of its state since its last emission. Between its input events, level
   l+1's memory decays and rotates with elapsed time, as every temporal memory layer does. Upper levels therefore
   process fewer, longer-lived events: an HM-RNN-style learned segmentation, but expressed as our race of clocks, with
   silence (no emission) as information. Expected upper-level event rate decays geometrically with depth when each
   level emits at rate rho < 1, so total work is bounded by a constant multiple of the base layer's work
   (sum rho^l < 1/(1 − rho)): depth becomes cheap in an event-sparse implementation.
3. **Top-down context.** Every level's current state is broadcast down into the residual stream at the token level
   (the bottom readout sees all levels, as Hourglass/MEGABYTE upsample), so slow upper states condition fast
   predictions.
4. **Depth-stable temporal memory.** Per-level timescale spectra: level l's decay rates initialize geometrically
   slower with l (fast at the bottom, slow at the top); state normalized as in LRU; calibrated local clipping per level.
5. **Local predictive learning at every level (F2).** Each level l is trained, besides the global next-token loss,
   on a local race likelihood: predict the content of the next upward event from level l−1 and the time until it
   (a temporal point process loss on the emission stream, silence-aware). Every level gets an O(1) credit path and
   learns asynchronously; the global loss still flows through the residual stream.
6. **Credit for emission decisions.** Emission is hard and sparse in the forward pass. Its gradient uses a
   straight-through estimator in this first implementation, with our counterfactual paired-route credit for the
   emission race as the stronger replacement once the construction passes the ladder. A target emission rate per level
   (rho = 1/4) prevents collapse to always or never emitting.

## 4. Falsifiable predictions and tests

- **Depth ladder (decisive):** L in {2, 4, 8, 16} at 1M tokens on the 65,528-target slice; pass if loss decreases
  monotonically with L and the deep hierarchy beats the keyed L2 member's 6.019. Then 4M (beat 5.521).
- **Hierarchy (H3, H4, external validity):** emission rate per level; horizon-resolved level ablation; upper-level emissions concentrate at linguistic boundaries (whitespace-leading tokens, punctuation,
  newline, end-of-document) above their base rate; mutual information between a level's emission and boundary tokens
  increases with level.
- **Long range:** history-reset cost (reset every 64 tokens) grows with depth; for the race core it was 0.004–0.008.
- **Work:** fraction of positions active per level falls roughly geometrically with level.
- **Ablations, same budget:** without local losses; without upward emission (every level at token rate); without
  top-down broadcast.

If the ladder fails, the per-level local losses tell which levels do not learn, and the emission statistics tell
whether the hierarchy forms at all; the next change follows from those measurements, not from a new grid.

## 5. Implementation status and the depth/cadence rule (15 October)

`experiments/r1_async_hierarchy_lm.py` (v2) implements sections 0 and 3: emission by a causal cadence race (logit beats a
running threshold tracking the level's target quantile, updated from past batches only), segment integration (each
upper event integrates every lower event since the level's previous emission and the histogram of their concept race
outcomes), a hard concept race over 32 slots per level (decision-tree-like branch choices; usage balanced against
collapse), event-sparse compressed sequences with exact continuous-time memory between a level's own events, keyed race
reads over a level's own events, zero-initialised top-down gates and local hazard / next-concept / deep-supervision
losses. Contracts: exact identity at initialisation, exact causality of predictions and of every level's emissions,
nesting, event memory equals the event recurrence (1.3e-6). On real FineWeb lanes after 16 updates the levels stay
alive with a geometric cadence: about 55 -> 12 -> 3 -> 1 events per 256-token lane, 29 -> 17 -> 9 -> 3 concepts used.

**Depth/cadence rule.** With cadence rho per level, level l has events only when the context holds about rho^(-l) base
events, so the number of useful levels grows like log(context)/log(1/rho). Depth therefore comes from levels times
blocks per level, and the slow levels need persistent state across windows (our persistent memory) rather than longer
attention windows. First language configurations: 2 token blocks + 3 levels (rho 0.35) and 4 token blocks + 4 levels
(rho 0.3), 1M tokens, queued behind plan B.

**Target applications (user direction).** The concept race is a learned decision tree over events: for typed tables,
each field arrives as a typed event and successive concept races are the tree's splits, with segment integration
combining a row's evidence. The cadence hierarchy is built for high-rate, low-information streams such as event
cameras (DVS Gesture data is available in `data/dvsgesture`): the token level absorbs raw polarity events, upper levels
fire rarely, only when integrated change warrants it, and carry gesture-level concepts, so compute and representation
both follow information rather than the raw event rate.

## 6. One primitive, three kinds of depth: the race graph

**Race node.** A node n holds persistent state S_n. An incoming event e defines a candidate set C_n(e) (addressed memory
keys, child branches, concept slots, or {emit, silence}); each candidate c has a clock whose law depends on (S_n, e, c);
the clocks race, and the winner w with its time τ_w becomes the node's output event to its child nodes (silence can win:
no event). A **race graph** is a directed network of race nodes. The probability of an outcome is the product of race-win
probabilities along its event path; learning is exact for the winner and counterfactual for losing candidates (the same
credit rule everywhere); inference is sparse because only winners propagate.

| Special case | Candidate set | Depth along |
|---|---|---|
| synchronous layer | one candidate, delay 0 | stack per event (representation depth) |
| keyed read / race attention | keys of past events | memory selection |
| decision cascade, tree output | branches of a tree | elimination rounds per event (decision depth) |
| cadence level (plan C) | {emit, silence} with delays | slower levels across time (temporal depth) |
| concept routing; tabular split | concept slots; typed comparisons | path through a tree |
| mixture of experts | experts | conditional compute |

**Composition.** One input event runs a synchronous stack (representation), resolves its output through a narrowing
race cascade whose rounds may read memory selected by earlier rounds (decision), and contributes to cadence races that
emit slower concept events (time); slow states return as context for later events. Decision nodes can use the memory
cadence nodes integrated; tables use typed comparison nodes, split nodes, leaf nodes and additive aggregation of many
shallow race-trees.

**First instance built: race-tree output cascade** (`experiments/r1_race_tree_lm.py`). The next token is the winner of
four successive 16-way races down a balanced tree over the GPT-2 vocabulary (16^4 >= 50,257), each round refining the
query with the branch already chosen; an exact copy race (keyed episodic votes over tokens in the lane) competes with the
tree through a null route, so the output law stays exactly normalised. Training uses exact path likelihood, so losing
branches receive their exact gradient (counterfactual credit in closed form); output work per token falls from 50,257
dot products to 64 plus the refinement steps. Planned next instances: per-token halting race (adaptive decision depth),
race-forest layers for typed tables, plan C on DVS Gesture.
