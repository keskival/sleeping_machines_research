# Native credit computation on relationship tokens

B5/R1 development, Curie, 12 October 2026. The objective is a general-purpose temporal/event substrate. This private sensor task tests acquired relationship state and useful route credit; it is not a replacement for properly tokenized language or a public Transformer comparison.

## Current construction

The forward actor reuses AddressedEventHeads: two temporal layers, two race heads, two receiver alternatives, eight values per head, separate keys/values, decaying/rotating persistent memory and hard selected writes. Shared parameters act on independently addressed node states; IDs retrieve numerical state and do not index learned identity embeddings. Future sensor queries discover the target plus at most seven recently observed sources, score learned keys, select one by an exponential race and decode its future bit. Receiver training uses the existing local counterfactual surrogate; source teaching pays for one actual nonwinner sensor decode.

`race_credit_sensor.py` builds credit from that same native substrate. A credit token contains target/source forward representations, their observed bits/ages, the requested horizon, observed relationship evidence and the kind of request or delivered outcome. A learned projection embeds this token. Two native temporal layers with two race heads/two receiver alternatives operate on persistent state addressed by (target, source). A linear readout emits predicted future forecast loss. There is no dense GRU or multilayer credit controller. Local projections, gates and readouts support the temporal computation.

Parameters learn token embeddings, keys/key reads, race clocks, input/output message transforms, gates, decay/rotation and the loss readout. Numerical memory learns episode relationships and changing context. Query tokens activate only the chosen relationship and, during training, one sampled alternative. Delivered feedback updates the observed relationship; alternative outcomes update memory only when audited. Memory capacity comprises visited relationships rather than an allocated dense all-pairs table. The present implementation does not deliver inter-node forward events or credit outside the bounded discovery set.

The credit function predicts utility, not a categorical node label or a backprop imitation target. Let c(j)-c(w) estimate the forecast-loss difference of alternative j and winner w. Independent25% audits provide d_hat + A/p*(d_actual-d_hat), whose conditional expectation equals the actual contrast. The credit-only arm uses that estimate in the paid conditional route-gradient surrogate. The joint arm also reads past credit memory to modify forward source scores. This prospective policy channel changes source selection itself. Factual prediction loss and audited alternative prediction loss teach the critic directly.

Credit races use their own RNG; actor and credit gradients are clipped separately. Numerical memory survives gradient truncation. Forecasts are stored when issued, scored only at delayed feedback, and parameters change only after feedback when no differentiable forecast remains pending. The critic receives the exact issued actor context, not a reconstructed future or hidden generator structure.

## Data and costs

The original four-root affine generator is an interface diagnostic; a global lookup could explain success. Source-pinned nonlinear v2 data now vary root factors8/16 independently of graph depth4/8, with separate new graphs, relabeling, time scaling, inactive capacity, hidden rewiring and independent foreign-event insertion. The foreign transformation preserves home queries and targets. Hidden parents/gates remain in separate oracle files, forbidden for fitting and selection. These broader data are prepared, not learned-bias evidence.

Charge source discovery, all candidate-context reads, selected decoder values, counterfactual decodes, actor and credit receiver proposals, both optimizers and acquisition. V1 `value_reads` counted selected decoder deliveries, not all memory traffic: each query also performs candidate_keys+1 context reads/transports. New drivers count discovery_context_reads explicitly. Credit updates and their key/value work have separate counters. Small counterfactual sensor decodes are cheap in this task, so no economy is presumed for a larger critic. CPU/RSS are measured; counts are not full FLOP/energy estimates. Computational arrivals may lag query time: contexts align at the later computation time using only already observed data.

Predicting absolute loss can bury a small route effect in common outcome variation. A diagnosed next teacher centers each route's revealed BCE on the same issued persistence-baseline BCE. For binary label probabilityp and logitsz,z0, variance of the relative loss is p(1-p)(z−z0)^2, versus p(1-p)z² for absolute loss. Both routes share the baseline, so their actual loss contrast stays unchanged. The native memory/projection/readout architecture is retained; only the observed teaching value changes. The baseline is fixed before feedback. This is the known actor-critic control-variate principle, not a claimed novel identity. Its contract checks real native-unit learning and unchanged exact-actor updates before any further fit.
