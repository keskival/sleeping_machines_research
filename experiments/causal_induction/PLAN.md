# Learn structural biases, then exploit them on new causal graphs

B5/R1 development diagnostic, Curie ownership. This serves sparse dynamic interaction routing and causal associative induction; it does not replace the properly tokenized language programme or add a public battle. The objective is a general-purpose temporal/event substrate, with this task testing one learned-structure capability.

## What must be learned

A hidden directed graph contains shared local binary mechanisms, sparse message delivery with delays, and persistent node state. Only timestamped node observations, observed exogenous root flips, requests and later sensor feedback reach the learner. Parent edges, gate identities and generator ancestry never train or select it. Generic addressed state and shared local functions are architectural primitives; the actual graph, temporal dependencies and useful credit-transfer pattern must come from observed data.

The important biases are learned causal locality, reusable local mechanisms and conditional independence. Equivalent addresses can exchange roles; unrelated events should not alter relevant credit; a learned mechanism should compose along previously unseen paths. An unseen delayed-error path should receive useful credit because of that acquired structure, not because a route identifier was memorized. Shared message modules/permutation support alone do not demonstrate acquisition: which graph edges and error couplings are useful must be inferred.

## Data and falsifiable generalization

`generate.py` implements asynchronous hidden XOR/copy affine circuits. The learner is not supplied a parity solver. Random independent root flips create observed interventions; only changed internal values emit events. Queries request a future node-state bit, and labels arrive at their delivery times. Gate states start at a declared zero convention. The generator avoids constant settled parity outputs; finite transient output marginals are not claimed equal across rewires.

Train on32 four-layer graphs,64 root interventions and sensor requests per graph. Freeze hyperparameters before eight new four-layer graphs and eight new eight-layer graphs. Each held-out graph has paired address relabeling,10x physical-time rescaling,128 extra inactive nodes, and an unannounced halfway rewiring. Contracts require paired target preservation where applicable and no past change from future rewiring. Different graphs require causal context acquisition; generator labels remain inaccessible.

Next data extension: independent-component foreign-event insertion/interleaving. It must preserve the queried component's state at delivery before becoming an admitted invariance test. The current generator does not implement that transformation; do not report it as completed.

## Models and controls

Use our integrated temporal/key-value/hard-route member, not a new dense carrier substituted for it. Preserve delayed/race computation, sparse addressed updates, persistent representations and paid counterfactual alternatives. Reuse the measured integrated R1 recipe where the sensor-query interface allows it; its proper-token language benchmark remains separate.

Compare the same native actor with ordinary causal factual/counterfactual credit, learned connected credit, frozen learned credit and credit-state reset. Keep actor, observations, initialization, causal exposure and selected activity matched. Add a same-family full-candidate learning diagnostic only if its cost is needed for the decision. No new Transformer/LSTM training is authorized. Published or already-trained references require matching observable inputs and scoring protocol; otherwise the result is a native mechanism/generalization test, not a Transformer win.

Primary: prequential sensor NLL and full work to fixed quality on new graphs/depth. Supporting: relabel/time/capacity sensitivity, post-rewire recovery, credit to held-out paths and error-transfer calibration from paid model counterfactuals. Count key discovery, selected values/writes, losing-route queries, actor/critic fitting, historical acquisition, optimizer work and inference. Measure actual CPU/RSS; no energy inference from clocks or FLOPs.

## Acquisition gate

Demonstrate a learned coupling on new graphs that disappears under frozen/reset/structure-scrambled credit controls while maintaining matched actor information. Then show the acquired coupling improves future sensor predictions or work. A hidden-graph support metric may diagnose errors after fitting; it cannot be a teacher or selection criterion. A halfway regime switch by itself is insufficient. A first prototype's failure diagnoses that prototype, not the family.

The currently admitted long B10 job remains the only training process. Data contract/preparation wait the host lock. Model admission follows completed data semantics and an integrated sensor-query driver; no free-standing predictor/variance ladder or unpriced supremacy claim.

Scope of the first generator: four exogenous root bits and affine local gates are a semantics/credit-transfer starting point, not a sufficient claim of deep compositional advantage. A complete acquisition benchmark must vary exogenous factor count independently of graph depth and add hidden nonlinear local mechanisms. Otherwise a compact global parity table could explain the apparent depth gain without learning local factorization. Include last-observed-state persistence and an online per-node root-context learner as information-matched controls; the hidden graph simulator is an oracle ceiling only. These broader generators and model controls are planned, not completed.
