# Useful route transfer, beyond persistence confidence

Curie, 12 October 2026. Owned B5/R1 engineering plan. The unchanged four-arm confirmation finishes first, including its registered early-stop rule. This plan authorizes no competing fit, public scoring or benchmark claim.

## Failure being addressed

The original native world-credit cohort improves log loss while every factual binary answer remains the last observed target bit. That is useful confidence learning, but it does not test whether learned source-choice credit transfers information which changes a decision. Audit each completed confirmation with issue-time observations before attributing its improvement to useful structural transfer.

The current actor head is a learned persistence logit plus a trainable route-conditioned residual. It can change an answer; no hard sign constraint forbids it. Zero changes therefore do not by themselves justify removing persistence, replacing the native architecture or blaming estimator capacity. Candidate discovery, delivered payload information, gradient scale and the frequency of predictable target changes are distinct possible failures.

## Binding capability gate

On a fixed complete prequential cohort, require all of the following:

1. Better overall NLL than exact observed-outcome credit, fixed-prior credit and conditional persistence credit from the same acquired actor/optimizer state.
2. Positive net useful answer changes relative to issue-time persistence: beneficial changes minus harmful changes > 0, with all scored targets included. Report both counts, accuracy and NLL per system, phase and generating depth.
3. A matched frozen-credit arm, with the same acquired critic, memory operations and actor training, to isolate online credit learning from reuse of an already useful belief. Independently restart numerical episode state while preserving acquired parameters and optimizer moments.
4. All source acquisition, candidate scoring, decoded alternatives, critic writes, actor/critic optimizer work and replay/audit work charged. Establish quality before a matched-quality complete-cost efficiency claim.

Targets whose truth differs from persistence are an explanatory analysis subset only. Never select a model or cohort on their labels, change the main denominator, or report their conditional accuracy as the complete task result. A small NLL improvement can be economically relevant even without answer changes, but it is a calibration result and receives that label.

## Ordered diagnosis and intervention

First replay completed forecasts with byte-matched public arrays, checking query IDs, issue/delivery times, labels and unique trace coverage. This step changes no training or input protocol.

Next, after the current confirmation's final decision, use source development systems to measure: persistence error rate; whether candidate deliveries distinguish subsequent flips before feedback; factual-versus-alternative logit gaps; and response-weighted outcome residuals. Label-dependent diagnostics are produced after delivery and never enter inference. Keep held-out target systems fixed and untouched during model selection.

Choose one intervention from that evidence, not a grid:

- If candidate discovery misses predictive source events, repair event/address discovery while retaining hard race selection and bounded deliveries. Changing only the critic cannot recover information never delivered to the actor.
- If actor responses carry information erased by the critic summary, supply already computed factual/alternative responses as typed native-world inputs. Register their action conditioning explicitly: a pair-conditioned posterior is not automatically one common all-route risk potential. Compare against frozen issued-forward-belief credit.
- If the persistence anchor dominates an informative residual, change only the residual teaching/scaling rule. Preserve the reference forecast at initialization and require matched exact-credit and frozen-credit arms. Do not remove a useful prior merely to force answer changes.

The native temporal computation, separate keys/values, sparse selected payloads, independently learned shared memory and delayed actual-outcome teaching stay present. New source models and cases receive unique run tags; completed drivers, checkpoints and result bytes stay frozen. Numerical contracts precede the integrated source fit, and a bounded source opportunity gate precedes any long deployment cohort.

## What would change the conclusion

Positive answer-transfer and online-over-frozen gates would support useful learned credit under these private systems. A failure identifies the diagnosed component and triggers one documented repair or stopping that variant. Neural-depth scaling, properly tokenized language transfer, real-world event forecasting and clockless hardware efficiency each require their own complete, protocol-matched experiments.
