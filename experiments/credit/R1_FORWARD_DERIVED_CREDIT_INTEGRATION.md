# R1: forward-derived credit in proper-token language

11 October2026. Task-sized next gate after prospective synthetic forward-credit confirmation. Work inside R1; no new dense external controls, public validation/TEST scoring, character redirect or AWS duplication.

## Failure and design reason

Synthetic depth4 route learning now has a confirmed stochastic-utility gain over prefix credit, but only four future forecasts with eight symbolic marks. That cannot establish usefulness for language or deep all-carrier learning. The sparse-query measurement also finds that thinning cheap54-route projections adds noise without a useful CPU wall reduction. Preserve full contraction at this small candidate scale and change the task, rather than extending the synthetic seed ladder.

Use the available native KeyedTokenLM checkpoint `curie_r1g2_keyed1_4M_s1_20261008T1840Z`: GPT-2 vocabulary50257, d64, two temporal layers/32 modes, four key heads/dk16, trained4,194,304 tokens. Its embeddings, elapsed-position complex state, predecessor-message keys and normalized full-vocabulary forecast are retained. Its existing whole-model pretraining is inherited work, not free credit acquisition. No pretrained Transformer is fitted or used as the forward model.

Concrete retained mechanisms: temporal state/phase/decay, separate persistent keys and values, predecessor messages, one selected optional hard addressed key write, full losing-route credit through reference projections, causal feedback, distinct optimizer states and document-boundary resets. The native token interface has dense normalized output and scores its written keys; this first integration does not certify internally sparse race layers, zero discovery cost or clockless hardware. Discrete token positions provide elapsed-time transport; silence likelihood is not a token target.

## Learner and counterfactual algebra

Add a declared fast readout vector z∈R64, with token logits

    native_logits_j(v) + E_v · z_j,

where the trained embedding E is fixed. This changes the native model's adaptation interface: it learns a shared low-rank lexical bias while the carrier/key/query producers stay fixed. The source failure being addressed is the cost and factorization break from updating all6M parameters independently in each counterfactual world. A reference learner and factual learner own separate z/Adam state; this is an initial restricted learner, not an all-carrier substitute.

An optional key write Δ to token address r changes future logits by β_j(Δ)1[v=r], with β determined by the produced query, learned head decay and elapsed positions. Because z does not feed the carrier/query/key producer, their forward state is shared across these learners. One source carrier pass supplies every candidate. Reference z learns causally from each observed target, while every alternative is projected through its current reference z. Full residual correction uses actual factual/reference losses; p1 adds no extra audit world once both are paid.

Projection cost need not copy50257 logits for each alternative. At each reference readout, compute stable leave-one-out log normalizers once with prefix/suffix log-cumulative sums. The alternative normalization is logaddexp(logZ_except_r, logit_r+β); subtract its altered target logit. This is exact for the declared one-address perturbation, including extreme probabilities, and still charges full-vocabulary normalization/scans. Each actual branch scores and updates its own64-dimensional fast state using the complete vocabulary distribution. No backpropagated-gradient labels train a small isolated critic; the credit response uses the pretrained forward representation and a supervised evolving learner.

## Gates before fitting

1. Numerical source-independent world contracts: projected/factual/reference forecasts, fast-vector gradients, final weights and Adam moments; zero-step static equivalence; future-suffix causality; selected and optional alternate addresses; physical no-op reuse. Validate random small vocabularies and the actual50257-vocabulary checkpoint. Source hashes/checkpoint SHA bound every result.
2. Document resets: observing EOS resets carried forward/key state, fast readout/optimizer and credit activations before the next document's forecast. Effects from an earlier document cannot cross a reset. Test a suffix crossing EOS separately before real episode fitting.
3. Bounded actual-token integrated smoke: fresh contiguous TRAIN suffix after4,194,304 tokens; do not access public/reserved score intervals. Readout and teacher predictions score before each target is revealed. Charge all carrier passes, full output work, reference/factual updates, projected routes, decoder scans, copies and memory.
4. Only after those gates, register an owned causal episode comparison with policy/credit settings and resource endpoints. Keep state across artificial credit windows; fast state and hard-write history require issued-version accounting. A reset-per-eight-target diagnostic is labelled as such and cannot stand in for persistent online learning.

The first module will expose exact projected-loss/readout primitives and independent native episode replay. It will not silently implement a training claim before contracts. A trainable connected route controller can subsequently use shared history plus trained token/key descriptors; its stochastic law is sampled by a positive-rate exponential race, with the same route-policy gradient identity. Full candidate contraction remains admitted unless measured discovery/projection costs justify a different budget.

## Decision and scale

A successful task-sized calibration/utility gate admits persistent causal policy learning. To claim learning efficiency or scaling, compare complete work to matched quality across actual learned depths and capacities under the depth plan, with all initialization/training charged. Frozen-carrier language and a64-dimensional fast head are diagnostic restrictions to repair after their contribution is measured, not the final objective. Additional reference learning beat static in gradient residuals but not confirmed utility on the synthetic test; measure both in language instead of assuming transfer.
