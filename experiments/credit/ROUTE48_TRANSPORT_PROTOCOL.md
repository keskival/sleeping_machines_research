# R1 carried optimizer transport: 48-target route-policy development

Registered before smoke and fit, 11 October 2026. Decision: does carried diagonal
optimizer transport improve issued stochastic route utility over static credit
on fresh private language prefixes? Longer returns address the measured later
learning effects missed by eight-target credit. This is an owned-model
engineering iteration, not a benchmark verdict.

Keep the native pretrained two-layer GPT-2-tokenized FineWeb source fixed.
Train three connected geometry-controller arms: zero, current-snapshot static,
and diagonal optimizer transport. Seed 98410, controller Adam 1e-4, width 64,
37,377 parameters; lexical Adam .01; .9 softmax plus .1 uniform exploration;
optional native key-write amplitude .25. Incoming keys, lexical state and Adam
moments carry between windows; document boundaries reset episode state.
Each issued policy version and action remain fixed for its 48-target return.
No future information enters the issued descriptors. Actual factual and no-op
reference learners provide the full-return residual correction. Alternative
transport trajectories are approximate; the reference replay must match exactly.

Fit 32 consecutive windows (1,536 targets, 32 controller updates) after 64
context tokens at source training boundary +32,768. Final checkpoint only.
No selection, clipping or tuning on scoring prefixes. This development TRAIN
region was used by earlier short-return engineering runs; it is not sealed.

Score eight fresh private TRAIN-tail prefixes at source boundary +262,144+256*i:
64 context tokens, 48 future targets, independent fresh key/lexical states.
Exact independent Adam learner costs for all issued routes score every actor's
stochastic expected NLL; also show greedy, initial, uniform, no-op and oracle.
Primary endpoint: transport-over-static mean NLL gain with 10,000 paired-prefix
bootstrap draws. Transport-over-zero and initial are additional endpoints.
A positive lower bound supports this single-initialization private development
endpoint. Diagnose unclear results using headroom, gradients and state mismatch.
Public DEV/TEST remain untouched.

Smoke: two windows and one distinct scoring prefix at source boundary +270,336.
Require carried contract, existing issued geometry/credit/accounting contracts,
finite gradients and real-vocabulary reference replay parity <=1e-10.
Full fit requires the source-bound completed smoke result.

Run one CPU thread through unique one-job run_safe queues. RSS cap 1.5 GB,
address-space cap 8 GB, minimum available memory 9 GiB, cgroup reserve 2 GiB.
Measure smoke before setting full-fit timeout; use tmux for the full fit.
Count context/discovery, full vocabulary work, duplicate factual/reference replay,
transport reference and alternative state updates, controller fitting, copies and
all exhaustive scoring. Report supported FLOPs and wall separately; unsupported
scalar/special/Adam arithmetic is included in wall. Earlier source pretraining
and contracts are additional. Do not transfer the separate 2.09x acquisition
measurement to this integrated implementation without measuring it.

Frozen carrier, nonrecurrent actor and short fixed returns remain explicit
mechanism gaps. This pipeline tests utility before expanding full-carrier/depth
learning or training connected multiscale boundary-credit functions.
