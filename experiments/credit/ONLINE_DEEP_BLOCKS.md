# B1/R1: exact deep online credit through structural blocks

The two-layer online3 Taxi learner reaches mean DEV 0.47696 at 20 passes versus 0.45653 without traces and 0.44175 with sequence BPTT (three seeds). Exact dense traces take about 85 minutes. This engineering project preserves that learner and removes only provably zero sensitivity entries and products. Curie owns learned compact credit; this AWS project provides its exact reference without duplicating critic fitting.

For layer 1, parameters of its readout R1 and layer 2 cannot affect its state. Its trace therefore stores only the prefix preceding R1. The input Jacobian du/dtheta has support only on E[mark], Gw and Gb; its contraction with the write Jacobian is a scatter and outer product, rather than a dense matrix product. Layer-2 traces for upstream parameters remain fully dense. Each layer-2 own parameter affects only its mode, so own traces store one local vector per mode instead of a mode-by-all-parameters array. Decay/rotation transports those same blocks; contracting receiver cotangents reconstructs every original parameter gradient.

This follows note 160 section 12 and retains complete cross-layer history. It changes neither forward clocks/memory, event likelihood, update schedule nor gradient truncation. Online weight-drift interpretation stays identical. The online3 member is a dense-write diagnostic, not a hard-routed integrated model or a sparse-learning result. Available cross-layer storage still grows with upstream parameters; these blocks do not prove scalable arbitrary-depth learning.

Pipeline: existing fixed-weight every-parameter BPTT contract with block traces; four changing-weight online batches checking likelihood, parameters and every Adam state; then complete-step measurements at B1/d16/n8, B16/d32/n16 (existing Taxi shape), B4/d64/n32. Everything runs through AWS run_safe slot 1 with immutable source hashes, one CPU thread, 2 GB RSS cap and 8 GiB available floor. No TEST reads. A source-bound comparison of actual Taxi TRAIN batches precedes any longer fit: retain learning behavior to 1e-9 and require at least 1.5x whole-step speed at the existing shape to justify adoption. Failure means diagnose and repair under fresh tags; never alter active online3 jobs.

Full fitting-quality/work curves and depth >=4 remain the next evidence gates. Neither tensor sparsity nor wall speed is reported as a FLOP/energy or leaderboard win.
